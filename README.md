# find-stock-reversal
Static website to find stock reversal

Quick Checklist After Saving:
If an empty market_screener_db.json file was created in your folder from the previous run, delete market_screener_db.json or just click "Refresh Stock List (NSE/BSE)" once the page loads.

Run python app.py and refresh [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Within 5 seconds, you will see the first batch of 25 stocks appear live in the table while the progress bar finishes the remaining batches up to 130+ stocks
